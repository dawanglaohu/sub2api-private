# 11 边界问题与异常处理

| 编号 | 场景 | 触发条件 | 期望行为 | 模块 |
|---|---|---|---|---|
| E-01 | 首次安装尚未完成 | 配置文件或数据库初始化标记不存在 | 只启动 setup 路径，不暴露常规业务路由；完成后再进入主应用 | M1 |
| E-02 | 配置或迁移失败 | 环境参数非法、数据库不可达、迁移超时或部分失败 | 启动失败并给出可定位错误，不带不完整 schema 对外服务 | M2 |
| E-03 | 进程退出时仍有请求和 worker | 收到 SIGINT/SIGTERM 或容器停止 | 停止接收新请求，限时等待 HTTP、插件和 worker；超时后可观测退出 | M1 |
| E-04 | Redis 缓存缺失、陈旧或不可用 | 缓存过期、重启、网络抖动、outbox lag | 只在明确配置的路径回源 DB 或重建；业务事实不由旧缓存覆盖，避免缓存击穿 | M2 |
| E-05 | 高风险认证限流无法判定 | Redis 故障或限流状态读取失败 | 登录、注册、2FA、refresh、OAuth start 等入口 fail-close，不放大攻击面 | M3 |
| E-06 | 身份或邮箱并发绑定 | 两个请求同时绑定同一 identity、email 或 alias | 事务与唯一约束只允许一个成功，另一个返回冲突，不生成重复用户/绑定 | M3 |
| E-07 | 非法 API Key 输入与枚举滥用 | Query key、超长 header、缺失/无效 Key 或高频失败 | 返回模糊且协议一致的错误，记录 ingress reject，并对滥用限流 | M3 |
| E-08 | Key 过期或额度耗尽后读取自身信息 | 调用 usage、billing introspection 或异步图片查询 | 继续做身份/主体/ACL 检查，但跳过计费执行，允许读取自身数据 | M3 |
| E-09 | 账号凭据经 DTO、日志或管理接口泄漏 | 展示/复制/测试账号，或上游错误包含 secret | 统一 redaction，仅在受控写路径解密；日志和响应不得出现 token/secret | M4 |
| E-10 | Sticky 账号满载或失去资格 | 绑定账号容量溢出、停用、模型不支持或利润门禁失败 | 保持持久 sticky 绑定不被容量溢出迁移；本次请求按规则等待、临时 failover 或失败 | M4 |
| E-11 | 调度缓存或 outbox 落后 | Redis 不可用、lag 超阈值、候选缓存不完整 | 在配置允许时受限回源 DB/全量重建；限制 QPS 和超时，避免雪崩 | M4 |
| E-12 | 上游配额或并发限制 | OpenAI 配额 429、Kimi 并发 403、账号 reset window 未到 | 区分永久/窗口耗尽与瞬时错误，按 reset 冷却账号；保留其他账号故障转移 | M4 |
| E-13 | 平台不支持端点或 Responses 子路径 | 非目标平台调用 embeddings/video/voice，或子路径不在 allowlist | 在调度前返回协议一致 404 并标记本地能力限制，不向上游转发 | M5 |
| E-14 | 首字节前的可重试上游失败 | transport error、可重试 429/5xx，且响应流未开始 | 排除失败账号并在上限内重选；耗尽后返回单一明确错误 | M5 |
| E-15 | 流开始后上游中断 | SSE/WS/stream 已向客户端写出后 read error | 不切换账号、不拼接第二响应；按协议发终止事件或关闭连接并记录错误 | M5 |
| E-16 | 客户端取消或 deadline 到期 | HTTP context cancel、WS 断开、等待队列超时 | 向上游和槽位等待传播取消，及时释放并发资源，不继续计费无效工作 | M5 |
| E-17 | 必须落账的 usage 事件拥塞 | usage queue 满、worker 停止或数据库短暂失败 | mandatory 记录不得静默丢弃；采用受控同步/重试/失败响应并保持 request ID 可追踪 | M6 |
| E-18 | 支付通知伪造、重复、乱序或迟到 | webhook 签名错误，同一 trade 重放，取消/过期后收到真实付款 | 先验签再幂等状态转换；有效迟到付款可恢复履约，重复通知只返回已处理 | M6 |
| E-19 | 退款远端与本地状态分裂 | 本地权益已扣减但 provider 失败，或 provider 成功而本地提交失败 | 事务/补偿回滚并写审计；无法自动一致时进入 pending/failed，禁止伪装成功 | M6 |
| E-20 | Worker 崩溃留下活跃任务或 billing hold | 进程重启、任务 lease 超时、提交前异常 | stale-active、延迟队列和未提交 hold 定期恢复；恢复操作幂等 | M7 |
| E-21 | 批量任务重复提交 | 同一 idempotency key、manifest hash 或 job/custom_id 重放 | 返回既有任务或唯一冲突，不重复占用配额、扣费或生成输出 | M7 |
| E-22 | 异步输出越权、过期或已删除 | 其他 Key 查询 task、输出超过 TTL、用户删除记录 | 校验所有权，过期/删除返回明确状态；清理对象与元数据但保留必要审计 | M7 |
| E-23 | Ops/监控链路不可用 | 聚合查询超时、日志 sink 或监控 runner 故障 | 网关主链路保持可用并记录降级；不得把观测故障误判成上游业务错误 | M8 |
| E-24 | Prompt Audit 启动或扫描不可用 | worker/repository 启动失败，或持久化 blocking policy 已存在 | 无阻断意图时降级为 ModeOff；已观察到 blocking 意图时仅相关网关 fail-closed | M8 |
| E-25 | 插件包不兼容或路径不安全 | manifest/schema/hash 不符、越界路径、超限资源、host 版本不匹配 | 安装前拒绝并清理临时文件，不启动二进制，不覆盖已有启用插件 | M9 |
| E-26 | 插件权威状态不可读或 runtime 不健康 | DB list 失败、health timeout、进程退出、多插件同时绑定 | 发布 unavailable route 并 drain 旧 runtime；禁止静默回落到不受控直连 | M9 |
| E-27 | 公共设置或 token refresh 瞬时失败 | 首次导航、网络抖动、401 并发刷新 | 设置未知不等于功能关闭；refresh 单飞并正确重放/登出，避免重定向循环 | M10 |
| E-28 | 发布后浏览器仍引用旧 chunk | dynamic import 返回 chunk/CSS load error | 最多每 10 秒自动 reload 一次；持续失败提示清缓存，不形成刷新死循环 | M10 |
| E-29 | UI 功能开关、后端模式或支付恢复不一致 | 设置尚未加载、用户角色变化、支付回跳丢失页面状态 | 前端给出可恢复路径，后端最终授权；禁止展示成功但后端未履约 | M11 |
| E-30 | 管理员高风险操作缺少再验证 | 修改支付/安全/身份设置，或 compliance 未确认 | admin auth 之外继续执行 audit、compliance/step-up；失败时不落部分配置 | M11 |
| E-31 | 管理员首页覆盖与动效降级 | `home_content` 非空、reduced-motion、页面隐藏或低性能环境 | 显式首页覆盖优先；蚁群动效暂停/降级，核心内容和导航仍可用 | M12 |
| E-32 | `ext:` 外链格式非法或 opener 风险 | 非绝对 HTTP(S)、空目标、JavaScript scheme 或新窗口链接 | 后端拒绝非法值；合法值新窗口打开并带 `noopener noreferrer` | M12 |
| E-33 | 管理台执行官方自更新覆盖二开 | 用户点击更新/回滚，或入口被上游重新显示 | `allowSelfUpdate=false` 隐藏执行入口；只保留版本检查，发布走私有镜像 SOP | M12 |
| E-34 | 上游 release 合并冲突或镜像版本标错 | tag 修改二开文件、workflow 权限限制、分支先于 tag 推送 | CI 停止；按 51 文件净差异审计解决，版本由可达 tag 解析，禁止猜 head SHA | M13 |
| E-35 | Smoke 污染生产或未备份就切换 | smoke 复用生产卷、UI marker/版本失败、backup 缺失或损坏 | smoke 使用临时 PG/Redis；健康、版本、品牌和备份校验全部通过后才 switch | M13 |
| E-36 | 回滚镜像与前向 schema 不兼容 | 新版已执行不可逆迁移，切回旧二进制 | 先核对迁移和备份；能兼容才 rollback，必要时停机并按已验证备份恢复 | M13 |
| E-37 | 公共设置、模型广场或公告读取状态不确定 | 设置缓存未加载/失效、DB 查询失败、功能开关与 require-auth 矛盾 | 前端保持 unknown；后端按身份、backend mode 与持久化开关最终判定，设置更新同步失效 HTML/CSP 缓存 | M14 |
| E-38 | 代理、渠道或定时探测访问不可信目标 | 管理员填写恶意 URL、DNS 指向私网、代理回退或探测无限等待 | 按安全开关执行 URL/主机校验、step-up 与超时；失败不保存半配置，不让探测成为 SSRF/资源耗尽入口 | M14 |
| E-39 | 兑换码、优惠码或分销额度被并发重放 | 同一码/幂等键重复提交、两请求并发核销、转账与余额更新竞争 | 由唯一约束、幂等记录和事务只结算一次；冲突返回既有结果或明确失败并保留审计 | M14 |
| E-40 | 备份、导入导出或数据维护泄漏/半完成 | 导出包含凭据、archive 超限/越界、恢复中断、清理脚本目标不明确 | 高风险操作要求 step-up；限制格式/大小/路径并使用临时与事务边界，失败保持原数据可恢复且不把凭据写入日志 | M14 |
| E-41 | 测试、fixture 或生成代码与实现漂移 | schema/proto/Wire/前端嵌入物已改但未重新生成，协议 fixture 仍描述旧行为 | 质量门校验生成物来源并运行对应单元/集成/构建测试；差异必须可重现，禁止手改生成文件掩盖漂移 | M15 |
| E-42 | 依赖漏洞例外失效或锁文件漂移 | pnpm/go 依赖变化、高危 advisory 无例外、例外缺字段/重复/过期 | frozen lock 与 Go module 校验通过；高危/严重例外按 package+advisory 精确匹配、有缓解措施和有效期，否则 CI 失败 | M15 |
| E-43 | 文档、OpenSpec、管理技能或资源与代码不一致 | API/配置/模型定价变化后 README/docs/spec/CLI/资源未更新，示例夹带凭据 | 同一变更同步更新权威文档和操作入口，运行示例/链接/覆盖脚本；只保存占位凭据并标清代码基线与生产状态 | M15 |
