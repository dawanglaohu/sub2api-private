# 05 技术栈

## 后端

- Go 单体服务，Gin HTTP 路由，Google Wire 依赖注入。
- Ent ORM + PostgreSQL 18，schema 在 `backend/ent/schema/`，迁移在 `backend/migrations/`。
- Redis 8 用于鉴权缓存、调度缓存、并发槽、队列、限流、锁和短期会话。
- Zap/slog 日志，内置 Ops 聚合、审计、Prompt Audit 和频道监控。
- 多上游 HTTP/WebSocket/SSE 适配，覆盖 Claude、OpenAI、Gemini、Grok、Antigravity、Bedrock 与国内兼容平台。
- gRPC 插件 API，插件进程由 host reconcile、健康检查和 drain。

## 前端

- Vue 3 + TypeScript + Vite + Pinia + Vue Router。
- Tailwind CSS；聚蚁主题通过 CSS variables 和 vendored WOFF2 字体实现。
- Vitest 负责组件、store、router 和 API client 回归。
- 前端嵌入 Go 二进制，也支持设置注入和静态资源缓存失效。

## 交付

- 多阶段 Docker 构建，Docker Compose 运行 app/PostgreSQL/Redis。
- GitHub Actions 构建私有 GHCR 镜像。
- 生产只钉 `custom-<sha8>` 不可变标签，发布执行 pull→smoke→backup→switch。

## 不可破坏的约束

1. 不给 `frontend/package.json` 增加聚蚁专用依赖；资源 vendored，降低 lockfile 冲突。
2. 聚蚁新功能优先放新目录；上游文件只做小而准的插入。
3. `upstream` 只读，所有二开开发在 `custom`。
4. 官方生产 Compose 不直接改，定制通过 override 与 `.env`。
5. 数据库迁移是前向行为；跨大版本回滚前必须检查 schema 兼容性和备份。
