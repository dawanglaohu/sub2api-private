## 备注

<!-- notes:begin -->
数据库绑定是插件启用状态的权威来源，每个实例独立 reconcile。状态不可读或 runtime 不健康时发布 unavailable route，禁止静默回落到绕过插件的直连；切换 runtime 时先发布一致状态再 drain 旧进程。
<!-- notes:end -->
