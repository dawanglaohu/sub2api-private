# M15-T1　维护全仓测试、fixtures 与生成物一致性

- 所属模块：[[M15]]　工程质量与项目资产：全仓测试、fixtures、依赖审计、OpenSpec/文档、开发工具、资源素材和生成物一致性
- 前置依赖：[[M1-T2]]、[[M2-T2]]、[[M5-T2]]、[[M8-T2]]、[[M10-T2]]、[[M14-T3]]
- 完成后解锁：[[M15-T2]]

## 输入 / 产出

- **输入**：Go/Vitest/Compose 测试、协议 fixtures、schema/proto/Wire 源
- **产出**：可重现的单元/集成/构建门和同步生成物

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) schema/proto/Wire/嵌入物变化时生成物与测试同步（[[E-41]]）
2) backend/frontend/deploy 按改动域运行对应测试
3) fixture 断言验证真实协议而非只匹配旧字符串

## 必须处理的边界

- [[E-41]]　测试、fixture 或生成代码与实现漂移
    - 触发：schema/proto/Wire/前端嵌入物已改但未重新生成，协议 fixture 仍描述旧行为
    - 期望：质量门校验生成物来源并运行对应单元/集成/构建测试；差异必须可重现，禁止手改生成文件掩盖漂移
