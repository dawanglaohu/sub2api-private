# M7-T2　维护输出存储、下载与清理

- 所属模块：[[M7]]　异步媒体与任务运行时：异步/批量图片、队列、worker、结算、恢复、输出存储与清理
- 前置依赖：[[M7-T1]]、[[M6-T2]]
- 完成后解锁：无，它不卡别人

## 输入 / 产出

- **输入**：任务主体、输出对象、TTL
- **产出**：授权下载、过期与删除流程

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 查询和下载校验 Key/用户所有权（[[E-22]]）
2) 输出过期与用户删除状态明确
3) 对象清理不破坏必要审计/账务记录

## 必须处理的边界

- [[E-22]]　异步输出越权、过期或已删除
    - 触发：其他 Key 查询 task、输出超过 TTL、用户删除记录
    - 期望：校验所有权，过期/删除返回明确状态；清理对象与元数据但保留必要审计

## 实施沉淀

<!-- notes:begin -->
对象存储 key 本身不是授权凭据，下载前仍需从任务主体校验 Key/用户所有权。清理按状态和 TTL 删除输出，但账务、失败原因和必要事件记录有独立保留责任，不能一次级联全部抹除。
