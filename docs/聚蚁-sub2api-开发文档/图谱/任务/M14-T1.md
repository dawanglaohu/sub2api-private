# M14-T1　维护公共设置、模型广场与渠道连接

- 所属模块：[[M14]]　站点运营与管理能力：公共设置/模型广场、公告、渠道/代理、兑换/优惠/分销、备份/数据管理和管理 CLI
- 前置依赖：[[M2-T2]]、[[M3-T2]]、[[M4-T1]]、[[M8-T1]]
- 完成后解锁：[[M11-T1]]、[[M11-T2]]、[[M14-T2]]、[[M14-T3]]

## 输入 / 产出

- **输入**：setting、announcement、channel/proxy 与 feature mode
- **产出**：公共设置、模型广场、公告、渠道/代理和自定义页面后端能力

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 设置未知时前端不误判，后端最终 fail-closed 并同步失效缓存（[[E-37]]）
2) URL/代理/探测执行安全校验、step-up 与超时（[[E-38]]）
3) 用户与管理员路由共享一致 feature gate

## 必须处理的边界

- [[E-37]]　公共设置、模型广场或公告读取状态不确定
    - 触发：设置缓存未加载/失效、DB 查询失败、功能开关与 require-auth 矛盾
    - 期望：前端保持 unknown；后端按身份、backend mode 与持久化开关最终判定，设置更新同步失效 HTML/CSP 缓存
- [[E-38]]　代理、渠道或定时探测访问不可信目标
    - 触发：管理员填写恶意 URL、DNS 指向私网、代理回退或探测无限等待
    - 期望：按安全开关执行 URL/主机校验、step-up 与超时；失败不保存半配置，不让探测成为 SSRF/资源耗尽入口

## 实施沉淀
