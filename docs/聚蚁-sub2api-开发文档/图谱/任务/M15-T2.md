- 前置依赖：[[M14-T3]]、[[M15-T1]]
- 完成后解锁：[[M13-T1]]

## 输入 / 产出

- **输入**：go.mod/sum、pnpm lock/audit、OpenSpec/docs/skills/tools/assets/resources
- **产出**：通过审计的依赖与可发现、无秘密、跟随代码演进的维护资产

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) frozen lock 与漏洞例外字段/匹配/有效期校验通过（[[E-42]]）
2) API/配置/定价变化同步文档、OpenSpec、管理 skill 和资源（[[E-43]]）
3) README/示例只使用占位凭据并区分代码与生产基线

## 必须处理的边界

- [[E-42]]　依赖漏洞例外失效或锁文件漂移
    - 触发：pnpm/go 依赖变化、高危 advisory 无例外、例外缺字段/重复/过期
    - 期望：frozen lock 与 Go module 校验通过；高危/严重例外按 package+advisory 精确匹配、有缓解措施和有效期，否则 CI 失败
- [[E-43]]　文档、OpenSpec、管理技能或资源与代码不一致
    - 触发：API/配置/模型定价变化后 README/docs/spec/CLI/资源未更新，示例夹带凭据
    - 期望：同一变更同步更新权威文档和操作入口，运行示例/链接/覆盖脚本；只保存占位凭据并标清代码基线与生产状态
