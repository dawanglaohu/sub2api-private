# M8-T2　维护 Prompt Audit 与安全策略

- 所属模块：[[M8]]　观测、频道监控与 Prompt Audit：Ops 指标/日志/告警、监控 runner、内容安全策略与审计事件
- 前置依赖：[[M3-T2]]、[[M5-T1]]
- 完成后解锁：[[M15-T1]]

## 输入 / 产出

- **输入**：prompt、policy、scanner 状态
- **产出**：allow/block decision 与审计事件

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 无阻断意图时启动失败降级 ModeOff（[[E-24]]）
2) 已持久化 blocking 意图时相关请求 fail-closed
3) payload 存储、日志和 UI 不泄漏敏感内容

## 必须处理的边界

- [[E-24]]　Prompt Audit 启动或扫描不可用
    - 触发：worker/repository 启动失败，或持久化 blocking policy 已存在
    - 期望：无阻断意图时降级为 ModeOff；已观察到 blocking 意图时仅相关网关 fail-closed

## 实施沉淀

<!-- notes:begin -->
启动失败时先判断是否已观察到持久化 blocking policy：有阻断意图则相关请求 fail-closed，没有则保持 ModeOff 让管理员可进入关闭/修复。Payload 保存和 UI 展示属于敏感数据面，不能为了调试默认记录完整 prompt。
