# M4-T1　维护账号、分组与凭据管理

- 所属模块：[[M4]]　账号、分组与调度：账号凭据、平台分组、模型路由、sticky、并发、配额和可调度资格
- 前置依赖：[[M2-T2]]、[[M3-T2]]
- 完成后解锁：[[M4-T2]]、[[M5-T1]]、[[M6-T1]]、[[M11-T2]]、[[M14-T1]]

## 输入 / 产出

- **输入**：管理员账号/组/OAuth 配置
- **产出**：加密账号、模型范围与组关系

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) CRUD 与批量操作保持事务一致
2) DTO/日志/测试结果执行凭据脱敏（[[E-09]]）
3) 删除、shadow、proxy 与平台类型关系可追踪

## 必须处理的边界

- [[E-09]]　账号凭据经 DTO、日志或管理接口泄漏
    - 触发：展示/复制/测试账号，或上游错误包含 secret
    - 期望：统一 redaction，仅在受控写路径解密；日志和响应不得出现 token/secret

## 代码位置

<!-- code:begin -->
- `backend/internal/handler/admin/account_handler.go` — 账号管理 API
- `backend/internal/handler/admin/group_handler.go` — 分组管理 API
- `backend/internal/service/account_service.go` — 账号 CRUD、加密凭据和状态
- `backend/internal/service/admin_group.go` — 分组、平台与模型配置
- `backend/internal/service/account_credentials_redact.go` — 凭据脱敏（E-09）
<!-- code:end -->

## 实施沉淀

<!-- notes:begin -->
