# M9-T1　维护插件契约、包与兼容检查

- 所属模块：[[M9]]　插件与扩展：manifest/gRPC 契约、包安装、兼容检查、进程 reconcile、灰度路由和 UI bridge
- 前置依赖：[[M1-T2]]、[[M2-T2]]
- 完成后解锁：[[M9-T2]]

## 输入 / 产出

- **输入**：插件 archive、manifest、host info
- **产出**：安全安装目录、bindings 与兼容结果

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) schema/hash/path/size/版本不符在启动前拒绝（[[E-25]]）
2) 安装失败清理临时文件
3) proto、manifest schema 与文档同步

## 必须处理的边界

- [[E-25]]　插件包不兼容或路径不安全
    - 触发：manifest/schema/hash 不符、越界路径、超限资源、host 版本不匹配
    - 期望：安装前拒绝并清理临时文件，不启动二进制，不覆盖已有启用插件

## 代码位置

<!-- code:begin -->
- `backend/pkg/pluginapi/v1/plugin.proto` — gRPC 服务与消息契约
- `backend/pkg/pluginapi/v1/manifest.schema.json` — manifest 校验契约
- `backend/internal/service/plugin_manifest.go` — manifest 解析
- `backend/internal/service/plugin_package.go` — archive、hash、路径和大小检查（E-25）
- `backend/internal/service/plugin_compatibility.go` — host/API 兼容判断
<!-- code:end -->

## 实施沉淀

<!-- notes:begin -->
插件包在写入正式安装目录和启动进程前完成 schema、hash、路径、大小与 host 兼容检查。失败清理只允许触及 installer 管理路径；不能跟随 archive traversal 或 manifest 提供的任意绝对路径。
<!-- notes:end -->
