## 输入 / 产出

- **输入**：BuildInfo、providers、server config
- **产出**：完整 Application 与可控 shutdown

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) HTTP middleware/routes 和嵌入前端按顺序组装
2) SIGTERM 限时关闭 server、plugin、worker（[[E-03]]）
3) cleanup 可重复且不泄漏 goroutine

## 必须处理的边界

- [[E-03]]　进程退出时仍有请求和 worker
    - 触发：收到 SIGINT/SIGTERM 或容器停止
    - 期望：停止接收新请求，限时等待 HTTP、插件和 worker；超时后可观测退出
