# M3-T2　维护 API Key、ACL 与授权中间件

- 所属模块：[[M3]]　身份、授权与安全：密码/OAuth/Passkey/2FA/JWT、API Key、ACL、限流、step-up 与审计边界
- 前置依赖：[[M3-T1]]
- 完成后解锁：[[M4-T1]]、[[M5-T1]]、[[M6-T1]]、[[M8-T2]]、[[M12-T2]]、[[M14-T1]]、[[M14-T3]]

## 输入 / 产出

- **输入**：API Key headers、用户/组/订阅
- **产出**：AuthSubject、Group 与协议化拒绝

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) Query/超长/无效 Key 统一拒绝并记 ingress（[[E-07]]）
2) usage/billing/task read 只跳过计费不跳过身份检查（[[E-08]]）
3) IP ACL、组和用户状态始终执行

## 必须处理的边界

- [[E-07]]　非法 API Key 输入与枚举滥用
    - 触发：Query key、超长 header、缺失/无效 Key 或高频失败
    - 期望：返回模糊且协议一致的错误，记录 ingress reject，并对滥用限流
- [[E-08]]　Key 过期或额度耗尽后读取自身信息
    - 触发：调用 usage、billing introspection 或异步图片查询
    - 期望：继续做身份/主体/ACL 检查，但跳过计费执行，允许读取自身数据
