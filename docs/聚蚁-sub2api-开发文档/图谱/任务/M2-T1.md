# M2-T1　演进 Ent schema 与数据库迁移

- 所属模块：[[M2]]　数据模型与基础设施：Ent schema、PostgreSQL 迁移、repository、Redis/S3/外部 client adapters
- 前置依赖：[[M1-T1]]
- 完成后解锁：[[M2-T2]]

## 输入 / 产出

- **输入**：业务实体与兼容要求
- **产出**：schema、migration、生成代码

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) schema 与 migration 同步
2) 迁移失败不带半成品对外服务（[[E-02]]）
3) 索引和唯一约束覆盖并发不变量

## 必须处理的边界

- [[E-02]]　配置或迁移失败
    - 触发：环境参数非法、数据库不可达、迁移超时或部分失败
    - 期望：启动失败并给出可定位错误，不带不完整 schema 对外服务

## 代码位置

<!-- code:begin -->
- `backend/ent/schema/` — schema、关系和索引定义
- `backend/migrations/` — 显式 SQL 迁移与说明
- `backend/internal/repository/migrations_runner.go` — 迁移执行入口
- `backend/ent/migrate/schema.go` — Ent 生成迁移描述
<!-- code:end -->

## 实施沉淀

<!-- notes:begin -->
唯一约束承担并发正确性，应用层 check-then-write 只能改善提示，不能替代数据库约束。迁移是前向发布的一部分；增加不可逆字段/索引操作时必须同时记录旧镜像是否还能读取新 schema。
