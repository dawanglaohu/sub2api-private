# M13-T2　执行 smoke、备份、切换与回滚验收

- 所属模块：[[M13]]　构建、发布与生产运维：上游 release 同步、私有镜像、隔离 smoke、备份、切换和 rollback
- 前置依赖：[[M13-T1]]
- 完成后解锁：无，它不卡别人

## 输入 / 产出

- **输入**：custom-SHA 镜像、生产 SOP
- **产出**：已验证部署或明确回滚

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) smoke 临时栈不挂生产卷且 backup 通过后才 switch（[[E-35]]）
2) rollback 前核对前向迁移兼容性（[[E-36]]）
3) 发布后检查健康/版本/品牌/日志并清理 smoke

## 必须处理的边界

- [[E-35]]　Smoke 污染生产或未备份就切换
    - 触发：smoke 复用生产卷、UI marker/版本失败、backup 缺失或损坏
    - 期望：smoke 使用临时 PG/Redis；健康、版本、品牌和备份校验全部通过后才 switch
- [[E-36]]　回滚镜像与前向 schema 不兼容
    - 触发：新版已执行不可逆迁移，切回旧二进制
    - 期望：先核对迁移和备份；能兼容才 rollback，必要时停机并按已验证备份恢复
