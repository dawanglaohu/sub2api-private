# M6-T1　维护用量、计价与订阅窗口

- 所属模块：[[M6]]　用量、订阅与支付：UsageLog、余额/订阅窗口、计价、订单、provider webhook、履约和退款
- 前置依赖：[[M2-T2]]、[[M3-T2]]、[[M4-T1]]
- 完成后解锁：[[M6-T2]]、[[M7-T1]]、[[M11-T1]]、[[M14-T2]]

## 输入 / 产出

- **输入**：token/模型/倍率/主体/订阅
- **产出**：UsageLog、扣费与窗口更新

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) usage 与余额/订阅更新保持幂等可追踪
2) mandatory 记录拥塞不静默丢失（[[E-17]]）
3) simple mode 与 standard mode 语义明确

## 必须处理的边界

- [[E-17]]　必须落账的 usage 事件拥塞
    - 触发：usage queue 满、worker 停止或数据库短暂失败
    - 期望：mandatory 记录不得静默丢弃；采用受控同步/重试/失败响应并保持 request ID 可追踪
