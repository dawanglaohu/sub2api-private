# M7-T1　维护异步与批量图片队列

- 所属模块：[[M7]]　异步媒体与任务运行时：异步/批量图片、队列、worker、结算、恢复、输出存储与清理
- 前置依赖：[[M4-T2]]、[[M5-T2]]、[[M6-T1]]
- 完成后解锁：[[M7-T2]]、[[M11-T1]]

## 输入 / 产出

- **输入**：图片请求、idempotency key、manifest
- **产出**：Job/Item/Event、队列任务与结算

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) worker 重启恢复 stale-active 和 billing hold（[[E-20]]）
2) 重放不重复建单/扣费/生成（[[E-21]]）
3) delayed mover 和 settlement 可重复执行

## 必须处理的边界

- [[E-20]]　Worker 崩溃留下活跃任务或 billing hold
    - 触发：进程重启、任务 lease 超时、提交前异常
    - 期望：stale-active、延迟队列和未提交 hold 定期恢复；恢复操作幂等
- [[E-21]]　批量任务重复提交
    - 触发：同一 idempotency key、manifest hash 或 job/custom_id 重放
    - 期望：返回既有任务或唯一冲突，不重复占用配额、扣费或生成输出
