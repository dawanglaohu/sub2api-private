# M14-T3　维护数据管理、备份与高级运营工具

- 所属模块：[[M14]]　站点运营与管理能力：公共设置/模型广场、公告、渠道/代理、兑换/优惠/分销、备份/数据管理和管理 CLI
- 前置依赖：[[M2-T2]]、[[M3-T2]]、[[M8-T1]]、[[M14-T1]]
- 完成后解锁：[[M11-T2]]、[[M15-T1]]、[[M15-T2]]

## 输入 / 产出

- **输入**：backup/import/export、system、scheduled test、error/TLS rules
- **产出**：可审计的数据运维、规则配置、维护命令和管理 CLI

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 导入导出/备份限制路径、格式和大小并要求 step-up（[[E-40]]）
2) 代理/错误透传/TLS/定时测试更新不落半配置（[[E-38]]）
3) 管理 CLI 先只读、明确目标、写后复查

## 必须处理的边界

- [[E-38]]　代理、渠道或定时探测访问不可信目标
    - 触发：管理员填写恶意 URL、DNS 指向私网、代理回退或探测无限等待
    - 期望：按安全开关执行 URL/主机校验、step-up 与超时；失败不保存半配置，不让探测成为 SSRF/资源耗尽入口
- [[E-40]]　备份、导入导出或数据维护泄漏/半完成
    - 触发：导出包含凭据、archive 超限/越界、恢复中断、清理脚本目标不明确
    - 期望：高风险操作要求 step-up；限制格式/大小/路径并使用临时与事务边界，失败保持原数据可恢复且不把凭据写入日志

## 实施沉淀

<!-- notes:begin -->
