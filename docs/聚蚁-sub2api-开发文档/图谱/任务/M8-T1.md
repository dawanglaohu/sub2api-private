# M8-T1　维护 Ops、频道监控与告警

- 所属模块：[[M8]]　观测、频道监控与 Prompt Audit：Ops 指标/日志/告警、监控 runner、内容安全策略与审计事件
- 前置依赖：[[M2-T2]]、[[M5-T2]]
- 完成后解锁：[[M11-T2]]、[[M14-T1]]、[[M14-T3]]

## 输入 / 产出

- **输入**：request/error/latency/token 事件
- **产出**：聚合、趋势、实时流量、告警与监控结果

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 观测故障不无条件阻断网关（[[E-23]]）
2) 请求 ID 可从错误追到主体和上游
3) 聚合/清理任务有锁、窗口和降级记录

## 必须处理的边界

- [[E-23]]　Ops/监控链路不可用
    - 触发：聚合查询超时、日志 sink 或监控 runner 故障
    - 期望：网关主链路保持可用并记录降级；不得把观测故障误判成上游业务错误
