# M12-T2　维护 ext 外链与私有发布安全边界

- 所属模块：[[M12]]　聚蚁品牌层：品牌首页、主题字体、蚁群动效、仪表盘增强、ext 外链和禁自更新边界
- 前置依赖：[[M3-T2]]、[[M11-T2]]、[[M12-T1]]
- 完成后解锁：[[M13-T1]]

## 输入 / 产出

- **输入**：custom menu、版本信息
- **产出**：安全外链与只读更新提示

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) ext 仅接受绝对 HTTP(S) 且新窗口隔离 opener（[[E-32]]）
2) `allowSelfUpdate=false` 阻止官方二进制覆盖（[[E-33]]）
3) 版本检查仍可用

## 必须处理的边界

- [[E-32]]　`ext:` 外链格式非法或 opener 风险
    - 触发：非绝对 HTTP(S)、空目标、JavaScript scheme 或新窗口链接
    - 期望：后端拒绝非法值；合法值新窗口打开并带 `noopener noreferrer`
- [[E-33]]　管理台执行官方自更新覆盖二开
    - 触发：用户点击更新/回滚，或入口被上游重新显示
    - 期望：`allowSelfUpdate=false` 隐藏执行入口；只保留版本检查，发布走私有镜像 SOP
