# M9-T2　维护插件 runtime、reconcile 与路由

- 所属模块：[[M9]]　插件与扩展：manifest/gRPC 契约、包安装、兼容检查、进程 reconcile、灰度路由和 UI bridge
- 前置依赖：[[M5-T2]]、[[M9-T1]]
- 完成后解锁：[[M11-T2]]

## 输入 / 产出

- **输入**：DB 权威状态、runtime health、rollout
- **产出**：单一受控 plugin route 与 drain 生命周期

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 权威状态不可读或 runtime 不健康时 unavailable（[[E-26]]）
2) 禁止多 OpenAI 出站插件同时启用
3) 状态变化后原子发布新 route 并 drain 旧进程

## 必须处理的边界

- [[E-26]]　插件权威状态不可读或 runtime 不健康
    - 触发：DB list 失败、health timeout、进程退出、多插件同时绑定
    - 期望：发布 unavailable route 并 drain 旧 runtime；禁止静默回落到不受控直连

## 实施沉淀

<!-- notes:begin -->
DB bindings 是权威状态，实例本地进程只是可重建副本。读不到权威状态、多插件同时绑定或 health 失败时 route 显式 unavailable；旧 runtime 先进入 draining，再在超时后退出，避免请求落到半切换状态。
