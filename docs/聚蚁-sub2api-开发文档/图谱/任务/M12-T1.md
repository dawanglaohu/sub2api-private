## 实施沉淀

<!-- notes:begin -->
管理员 home_content 是显式更高优先级，聚蚁首页只是默认渲染面。动效读取主题变量并在 reduced-motion/页面隐藏时降级；主题只覆盖品牌交互位，平台身份和状态语义颜色保持稳定。

2026-08 动效层 v2（finesse 流程，用户确认 A+B 方向后落地）：①蚁群引擎升级为 2.5D（三景深视差+分段躯体+驮光粒归巢+入巢脉冲），性能靠粒子封顶 90/精灵图辉光（禁逐帧 shadowBlur）/DPR≤2/三重暂停兜底；主页背景层改 fixed 后画布从整页高变视口尺寸，内存与 iOS canvas 面积限制风险同时消除。②主页动效预算：入场浮起、管线颗粒汇流（rAF+getPointAtLength，元素与长度缓存）、模型跑马灯（全站唯一 marquee）、bento 两张主演示卡（多源归一颗粒流+八格负载波）不对称破除 6 连同卡、暗色宣言面板。③滚动浮现采用 JS 武装模式：data-jy-reveal 元素先由 composable 加 .jy-reveal 再由 IO 放行 .jy-in，无 JS/reduced-motion 永不隐藏内容（Playwright 实测滚动后 18/18 放行）。④后台壳改浮动侧边栏+悬浮顶栏（≥lg），侧栏不加 overflow:hidden 以免裁剪主题菜单弹层；主列 margin 与侧栏宽度联动改 276/92px。⑤v-jy-count 数字滚动是纯展示指令，模板里数字插值改由指令渲染避免双写。⑥回填修复 docUrlSanitization.spec 存量漂移（HEAD 的 HomeView 本无 sanitizeUrl，壳化时漏改）。

2026-08 v3 反馈迭代（用户验收不满意：蚂蚁太小/页面卡/不够冲击/像模板）：⑦引擎从 Canvas 换轨 SVG（JuyiSwarmField.vue）：蚂蚁改为手绘虫（径向渐变躯体着色+地面投影+尾迹随组变换零额外开销），16 只大尺寸三景深替代 90 只尘埃点，逐帧仅写 style.transform 且 30fps 节流；性能採样 3 秒 0 long task。真正的卡顿源是 backdrop-filter 叠在动画层上——登录卡/bento/标签/平台墙全部去 blur 改实底，这是比换引擎更大的收益。⑧色彩律动：hero 关键词流动渐变字（i18n 拆 titleA/B 实现，每页最多一处动态渐变）、登录页双漂移色斑、暗色宣言面板大字+静态渐变句、CTA 呼吸辉光、主页色带分区+行军蚁分隔线。⑨去模板味：hero 分行大字堆叠、宣言双行渐变句、bento 顶部发丝线悬停拉丝、管线下颗粒加大+悬停路径加速。⑩登录卡隐喻：巢房对准卡片正后方，蚂蚁归巢=登录。⑪教训：<use> shadow DOM 与 JS 动态创建的 SVG 节点都拿不到 Vue scoped 样式标记，必须用非 scoped 样式块（jy- 前缀防撞）；SMIL 动画无法用 CSS 暂停，reduced-motion 降级只能 display:none 隐藏运动元素。
