# M5-T1　维护入站协议路由与能力门控

- 所属模块：[[M5]]　协议网关与上游适配：入站路由、协议转换、能力门控、HTTP/WS/SSE 转发、failover 与取消传播
- 前置依赖：[[M1-T2]]、[[M3-T2]]、[[M4-T1]]
- 完成后解锁：[[M5-T2]]、[[M8-T2]]、[[M11-T1]]

## 输入 / 产出

- **输入**：Claude/OpenAI/Gemini/Codex 请求
- **产出**：标准化 endpoint、platform 与 handler dispatch

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) aliases 使用同一 auth/limit/normalization 链
2) 不支持能力和 Responses 子路径在调度前拒绝（[[E-13]]）
3) 错误体保持入站协议语义

## 必须处理的边界

- [[E-13]]　平台不支持端点或 Responses 子路径
    - 触发：非目标平台调用 embeddings/video/voice，或子路径不在 allowlist
    - 期望：在调度前返回协议一致 404 并标记本地能力限制，不向上游转发
