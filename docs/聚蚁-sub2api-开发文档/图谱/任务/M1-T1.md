# M1-T1　维护配置加载与首次安装路径

- 所属模块：[[M1]]　运行时、配置与安装：进程入口、环境配置、首次 setup、Wire 组装、HTTP 生命周期和嵌入前端
- 前置依赖：无，可直接开工
- 完成后解锁：[[M1-T2]]、[[M2-T1]]

## 输入 / 产出

- **输入**：环境变量、config、setup 状态
- **产出**：可验证的 bootstrap/setup 生命周期

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 未初始化时只进入 setup（[[E-01]]）
2) 配置或迁移错误阻止主应用启动（[[E-02]]）
3) 默认值与 Compose 示例一致

## 必须处理的边界

- [[E-01]]　首次安装尚未完成
    - 触发：配置文件或数据库初始化标记不存在
    - 期望：只启动 setup 路径，不暴露常规业务路由；完成后再进入主应用
- [[E-02]]　配置或迁移失败
    - 触发：环境参数非法、数据库不可达、迁移超时或部分失败
    - 期望：启动失败并给出可定位错误，不带不完整 schema 对外服务
