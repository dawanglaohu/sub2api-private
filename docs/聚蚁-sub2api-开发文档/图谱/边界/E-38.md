# E-38　代理、渠道或定时探测访问不可信目标

| | |
|---|---|
| 触发条件 | 管理员填写恶意 URL、DNS 指向私网、代理回退或探测无限等待 |
| 期望行为 | 按安全开关执行 URL/主机校验、step-up 与超时；失败不保存半配置，不让探测成为 SSRF/资源耗尽入口 |
| 归属模块 | [[M14]] |
