# 09 UI

本节是聚蚁品牌层的设计规范。所有取值提取自真实实现，事实源优先级：`frontend/src/styles/juyi.css`（主题变量/字体/动效）→ `frontend/tailwind.config.js`（阴影/渐变/动画 token）→ `frontend/src/composables/useJuyiAppearance.ts`（主题与字体切换）。改设计先改这三处代码，再同步本节。

## 信息架构

- 公共面：首页、登录/注册、OAuth callback、Key Usage、模型广场和法律文档。
- 用户面：Dashboard、Keys、Usage、订阅、充值/订单、兑换、渠道状态、个人资料与批量图片指南。
- 管理面：Dashboard、Accounts、Groups、Users、Subscriptions、Usage、Ops、频道监控、支付、插件、风控、设置与备份。
- Setup 面：数据库和管理员未初始化时独立于常规应用启动。

## 色板

主色是可切换的 CSS 变量族 `--jy-p-50…950`（rgb 三元组，配合 Tailwind `<alpha-value>`），默认蜜琥珀。以下为核心命名值：

| 名称 | 值 | Token | 用途 |
|---|---|---|---|
| 蜜琥珀 | `#ED9E13` | `--jy-p-500` | 品牌主色：按钮、链接、激活态、图表主色、glow 投影 |
| 蜂蜡高光 | `#FACC4E` | `--jy-p-300` | 亮色强调、hover 提亮 |
| 巢框深琥珀 | `#D17E09` | `--jy-p-600` | 渐变终点、主按钮 hover、正文链接 |
| 暖纸底 | `#FBF9F3` | JuyiHome 亮色页底 | 落地页底色（比纯白暖，衬托琥珀） |
| 巢室暖褐 | `#362E23` | `dark-800` | 暗色容器、表格 sticky/固定列、暗渐变起点 |
| 巢底暖黑 | `#16110B` | `dark-950` | 暗色页底、暗渐变终点 |
| 信息素青 | `#2CB1A6` | `pheromone-500` | 蚁径辅色：管线渐变、mesh 光斑，延续上游 teal 认知 |
| 暖灰文本 | `#CDC6B6` / `#ABA08A` | `dark-300/400` | 暗色次要文本（暖灰，不用冷 slate） |

中性色 `accent` 族是冷蓝灰（slate），只用于边框、分隔、表格中性底；不得与暖褐背景大面积混排。

### 四套主题

`data-jy-theme` 切换，`useJuyiAppearance` 写入 localStorage（`jy-theme`），启动时 `initJuyiAppearance()` 在挂载前套用以避免闪烁。默认主题不写属性（删除 `data-jy-theme`），其余主题写 `pheromone` / `nightfall` / `ember`。

| 主题 | key | 色板 | 主色（500） | 定位 |
|---|---|---|---|---|
| 蜜琥珀（默认） | `honey` | 琥珀 50–950 | `#ED9E13` | 品牌默认，暖金 |
| 信息素青 | `pheromone` | teal 50–950 | `#14B8A6` | 延续上游 teal 认知 |
| 靛夜 | `nightfall` | indigo 50–950 | `#6366F1` | 冷静夜间 |
| 炭玫 | `ember` | rose 50–950 | `#F43F5E` | 高对比替代 |

每套都是完整 50–950 阶梯（见 `juyi.css`），不是单色替换——所有 `primary-*` 用法在四主题下自动成立。

## 字体

三角色体系，`--jy-font-sans` 控制正文，`font-display` 与 `font-mono` 为独立 Tailwind token：

| 角色 | 字体 | 来源 | 用途 |
|---|---|---|---|
| 展示体 | Space Grotesk variable（300–700） | vendored `space-grotesk-latin-var.woff2`（约 22KB，仅拉丁） | 字标、hero 标题、端点标签 |
| 正文 | 系统黑体栈（system-ui + PingFang SC / Microsoft YaHei） | 系统自带 | 全站界面文本 |
| 数据/代码 | IBM Plex Mono 400/600 | vendored 两个 woff2（约 30KB，仅拉丁） | 端点 URL、curl 示例、统计数字 |

字体三模式 `data-jy-font`：`default`（黑体，默认）、`serif`（Georgia + Noto Serif SC / Songti SC，阅读型）、`mono`（IBM Plex Mono 全站）。持久化在 localStorage `jy-font`。

刻意决策：**展示体只覆盖拉丁字符**，中文回退系统字体——字体资产总共约 52KB，不为视觉统一引入兆级中文字体包。新页面不得因此引入额外字体文件。

## 阴影、渐变与几何

- 投影：`shadow-card`（1px 双层微影）、`shadow-card-hover`（10px 40px 浮起）、`shadow-glass`（8px 32px 玻璃）、`shadow-glow` / `glow-lg`（primary-500 的 0.25/0.35 光晕，只给主 CTA 和激活态）。
- 渐变：`gradient-primary`（135deg，p500→p600）、`gradient-dark`（#362E23→#16110B）、`mesh-gradient`（三 radial 光斑：primary 0.12/0.08 + 信息素青 0.08，仅 hero 级背景）。
- 几何：常规容器 `rounded-xl/2xl`，大容器 `rounded-4xl`（2rem）；蜂窝六边形用 `.hex-cell`（clip-path 十二点多边形），账号蜂巢与平台徽章共用。
- 纹理：`.juyi-hex-pattern` 内联 SVG 蜂窝，亮色 `#C9871A` @ 0.07、暗色 `#F7B62B` @ 0.05——纹理必须弱到“近看才发现”。

## 签名元素：蚁径管线

品牌的隐喻“多订阅聚合成一个端点”被直接画出来，是全站唯一的装饰性主角，其他一切保持克制：

1. **`AntTrailPipeline`**（落地页 hero）：四条订阅源 path（stroke 1.8）汇聚合并为一条主干（stroke 2.6）通向 `ENDPOINT` 标签；虚线粒子沿 path 行进（`ant-march`：dasharray 2.5/8，1.15s linear infinite，四路以 -0.3s 阶梯错相），中心 halo 圆（r=64）以 `ant-glow`（3.2s，透明度 0.35→0.7）呼吸；标签用 Space Grotesk + IBM Plex Mono 双字体。
2. **`JuyiSwarmCanvas`**（环境层）：登录/注册（density 40，含蜂窝网 showHex）与首页（density 52、intensity 0.9、无蜂窝网）的蚁群游走；蚂蚁数量按视口面积缩放 `density × min(1.5, W×H/(1280×800))`；透明度基准暗色 1.0 / 亮色 0.75 × intensity；dpr 上限 2。
3. 降级铁律：`prefers-reduced-motion` 只渲染一帧静态画面；`visibilitychange` 隐藏时暂停 rAF；`.ant-path/.ant-glow` 在 reduced-motion 下动画置 none。

新页面可以复用这套词汇（蜂窝、蚁径、光晕），但不得再发明第二个全屏动画主角。

## 布局概念

落地页（JuyiHome）：`max-w-6xl` 单列叙事，亮色 `#FBF9F3` + 蜂窝弱纹理 + 两个 blur 光斑（primary-400/15、primary-500/10）打底；hero 的论点就是管线图——先看懂“聚合”，再读三步接入（真实 curl）与特性蜂巢。控制台侧：暖褐底色的 DataTable（sticky 表头/固定列 `#362E23`/`#241E16`），信息密度服从可扫读。

## 反默认清单

以下是当前 AI 生成设计的三种模板脸，聚蚁明确不走：

1. **奶油底 + 高对比衬线大标题 + 赤陶点缀**——聚蚁亮色底虽也是暖纸，但标题走黑体/Space Grotesk，点缀是蜜琥珀；宋体只是可选阅读模式，不是品牌字体。
2. **近黑底 + 单一荧光强调色**——聚蚁暗色是**暖褐黑**（#16110B/#362E23），连中性文本都是暖灰；荧光感只允许 glow 投影，不给大面积底色。
3. **报纸风细规则线 + 零圆角 + 密排栏**——聚蚁用圆角、柔影、蜂窝几何，拒绝 hairline 满屏。

另有一条工程红线：不为“视觉统一”新增字体文件或 npm 依赖（见 05-技术栈）。

## 文案规范

词汇是界面的一部分，规则与令牌同样硬：

- 按钮写结果：「复制」「保存更改」「切换到暗色」；不用「提交」「确定」这类不说明后果的词。
- 动作全程同名：「生成 Key」的按钮，完成后 toast 是「已生成」，不是「操作成功」。
- 错误说原因 + 下一步，不道歉不含糊：沿用协议化错误（如 `API_KEY_QUOTA_EXHAUSTED`「API key 额度已用完」）；表单错误指到具体字段。
- 空态是邀请：说明这里会有什么 + 第一步动作，不放插图凑数。
- 术语全站同名：端点（endpoint）、分组（Group）、账号（Account）、用量（Usage）；平台名保留英文原名（Claude/OpenAI/Gemini/Grok），不翻译。
- 语气平实，不用营销腔和感叹号；句子用句式大写规范书写（中文界面以句号结尾的完整句为主）。

## 交互和无障碍

- `JuyiSwarmCanvas` 在 `prefers-reduced-motion` 或页面隐藏时降级，不能持续占用 CPU/GPU。
- 站点 Logo 与自定义 SVG/URL 必须经过 sanitizer；外链使用 `target=_blank` 时同时设置 `noopener noreferrer`。
- Sidebar 折叠态保留 title/aria-hidden；移动端由 overlay 关闭。
- 可见键盘焦点（focus ring 走主题色）与触达目标尺寸不因视觉风格牺牲。
- `home_content` 是管理员显式覆盖，存在时必须优先于聚蚁默认首页（E-31）。
- 功能开关未加载时菜单采用宽容显示，最终访问控制由后端决定。

## 上游合并策略

不重写上游大组件以追求视觉统一。品牌页面与动效放新文件；对 DataTable、GroupBadge、Dashboard、Sidebar、HomeView 的修改保持小而可审计。上游新增语义颜色或功能 import 时先保留功能，再判断是否收编为主题色。
