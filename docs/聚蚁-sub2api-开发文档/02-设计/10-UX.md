# 10 UX 与关键流程

## 界面状态与文案约定

四个关键流程（下图）之外的通用状态约定，与 09-UI 的文案规范同源：

| 状态 | 约定 | 反例 |
|---|---|---|
| 加载 | 骨架屏或 NavigationProgress；超过瞬时才展示，不闪烁 | 全屏转圈盖住可交互内容 |
| 空态 | 说明这里会有什么 + 第一步动作（「还没有 API Key，创建第一个」） | 只放插画不给出路 |
| 错误 | 协议化错误原样呈现 + 下一步动作；字段错误定位到字段 | 「操作失败」无原因、道歉腔 |
| 成功 | 与触发动作同名（「已生成」「已保存」）；金额/配额变化回显数字 | 万能「操作成功」 |
| 功能关闭 | 设置成功加载且显式为 false 才隐藏；未知保持宽容显示 + 后端兆底（E-27） | 瞬时加载失败当成“功能下线” |
| 危险操作 | 名称写后果（「删除账号」），二次确认复述对象；管理员高危走 step-up（E-30） | 「确定」弹窗无对象 |

## API 网关请求

```mermaid
sequenceDiagram
    actor C as API 客户端
    participant M5 as M5 协议网关
    participant M3 as M3 身份授权
    participant M4 as M4 账号调度
    participant U as 外部 AI 平台
    participant M6 as M6 用量计费
    participant M8 as M8 观测审计
    C->>M5: 协议请求 + API Key
    M5->>M3: 校验 Key / 用户 / 组 / ACL
    alt 凭据非法或主体不可用（E-07）
        M3-->>C: 协议化 4xx + ingress reject
    else 鉴权通过
        M3-->>M5: AuthSubject + Group + Subscription
        M5->>M5: 端点归一与能力门控
        alt 平台不支持能力或子路径（E-13）
            M5-->>C: 404，不进入调度
        else 能力可用
            M5->>M4: 模型 + session + 排除账号
            M4-->>M5: 账号 + 等待/并发决策
            M5->>U: 转换后的 HTTP / SSE / WS 请求
            alt 首字节前可重试错误（E-14）
                U-->>M5: 429 / 5xx / transport error
                M5->>M4: 排除失败账号后重选
                M4-->>M5: 下一账号或耗尽
            else 响应已开始
                U-->>M5: headers + stream
                M5-->>C: 原协议流
                opt 流中断（E-15）
                    U--x M5: read error
                    M5-->>C: 协议安全终止，不拼接第二上游
                end
            end
            par 结算
                M5->>M6: usage / token / cost 事件（E-17）
            and 观测
                M5->>M8: request ID / latency / error
            end
        end
    end
```

## 面板登录与身份绑定

```mermaid
sequenceDiagram
    actor U as 用户
    participant M10 as M10 前端应用壳
    participant M3 as M3 身份授权
    participant R as Redis
    participant M2 as M2 数据层
    U->>M10: 登录、Passkey 或 OAuth
    M10->>M3: credential / callback / pending flow
    M3->>R: 高风险入口限流
    alt Redis 不可判定（E-05）
        R--x M3: unavailable
        M3-->>M10: fail-close 429/503
    else 允许尝试
        M3->>M2: 事务校验 identity/email/alias
        alt 并发绑定或别名占用（E-06）
            M2-->>M3: unique/conflict
            M3-->>M10: 明确冲突，不创建重复身份
        else 身份确认
            M2-->>M3: User + bindings
            M3-->>M10: access/refresh session
            M10-->>U: 返回原目标页
        end
    end
```

## 支付与退款

```mermaid
sequenceDiagram
    actor U as 用户
    participant M11 as M11 用户控制台
    participant M6 as M6 用量支付
    participant P as 支付服务商
    participant M2 as M2 数据层
    U->>M11: 创建充值或订阅订单
    M11->>M6: POST order
    M6->>M2: 写 PENDING + provider snapshot
    M6->>P: 创建支付
    P-->>U: 收银台 / QR / SDK
    P->>M6: 签名 webhook
    alt 伪造、重复或迟到通知（E-18）
        M6->>M6: 验签 + 幂等状态转换
        M6-->>P: 拒绝或返回已处理
    else 首次有效支付
        M6->>M2: PAID → RECHARGING → COMPLETED
        M6-->>M11: 余额/订阅可见
    end
    opt 用户或管理员退款
        M11->>M6: refund request
        M6->>M2: 原子扣减/冻结权益
        M6->>P: provider refund
        alt provider 失败（E-19）
            M6->>M2: 回滚本地扣减 + 审计
        else 成功或 pending
            M6->>M2: REFUNDED / PARTIAL / REFUND_PENDING
        end
    end
```

## 上游版本发布

```mermaid
sequenceDiagram
    actor O as 维护者
    participant G as GitHub upstream
    participant M13 as M13 构建发布
    participant S as 隔离 smoke 栈
    participant D as 生产数据库
    participant P as 生产容器
    M13->>G: fetch 最新 release tag
    M13->>M13: merge --no-ff 到 custom
    alt 合并冲突（E-34）
        M13-->>O: CI 失败，停止构建
        O->>M13: 按 51 文件净差异审计后解决
    else 构建成功
        M13->>M13: 推 custom-SHA 不可变镜像
        O->>S: pull + 临时 PG/Redis smoke
        alt health/version/聚蚁标记失败（E-35）
            S-->>O: 停止，不触碰生产
        else smoke 通过
            O->>D: 执行并校验全库备份
            O->>P: switch 到 custom-SHA
            alt 健康或公网验收失败（E-36）
                O->>P: rollback 到 previous-image
                O->>D: 核对迁移兼容，必要时按备份恢复
            end
        end
    end
```
