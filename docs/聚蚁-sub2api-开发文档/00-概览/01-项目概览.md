# 01 项目概览

## 项目定位

聚蚁是上游 `Wei-Shaw/sub2api` 的私有品牌二开。系统把多个 AI 平台订阅账号、API Key 与配额汇聚为统一网关，对客户端提供 Claude、OpenAI、Gemini 兼容接口，同时提供用户面板、管理控制台、计费支付、运行观测、异步媒体任务和插件扩展能力。

## 当前代码基线

- 二开分支：`custom`，当前 commit `ec28de3f9240b834ee533399ef2e0d098f46ace1`。
- release 合并提交：`ff078d8659c54832b057c1bfaa2dc8ca430ccf68`。
- 私有远端：`private/custom` 与本地 `custom` 对齐。
- 生产镜像：`custom-ff078d86`，自报版本 `0.1.183`。代码基线比生产多一个纯文档提交，不代表生产二进制落后。

## 关键能力

1. 多协议 AI API 网关和平台能力门控。
2. 账号、分组、模型路由、粘性会话、并发与配额感知调度。
3. 用户、订阅、API Key、用量、余额、支付和退款闭环。
4. 异步/批量图片、视频、语音、搜索等扩展能力。
5. Ops、频道监控、Prompt Audit、审计日志和插件运行时。
6. 聚蚁品牌首页、主题字体、蚁群动效、端点快复和账号蜂巢视图。
7. 私有 GHCR 不可变镜像、隔离烟测、备份、切换与回滚 SOP。

## 知识库使用方式

从 [[_MOC]] 开始，不要从头通读全部章节。按模块进入 `图谱/模块/`，按维护任务进入 `图谱/任务/`，按失败场景进入 `图谱/边界/`。代码位置使用相对路径，不对代码文件创建 wikilink。
