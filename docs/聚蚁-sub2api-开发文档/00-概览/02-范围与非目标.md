# 02 范围与非目标

## 本知识库覆盖

- Go 后端启动、配置、Wire 组装、HTTP 边界与优雅关闭。
- Ent/PostgreSQL、Redis、S3、迁移和 repository adapters。
- 认证、OAuth、Passkey、2FA、JWT、API Key、ACL 与安全审计。
- 账号/分组管理、调度、协议转换、上游转发、流式响应与 failover。
- 用量、订阅、计费、支付、退款和异步任务。
- Ops、频道监控、Prompt Audit 与插件运行时。
- Vue 前端、用户/管理员控制台和聚蚁品牌层。
- CI、镜像、烟测、备份、切换和回滚。

## 明确非目标

- 不把 1174 个 `service/` 文件逐个抄进文档；只记录入口、责任边界和高风险位置。
- 不复制密钥、token、生产数据库内容、服务器 `.env` 或 OAuth 凭据。
- 不把移动标签 `custom-latest` 当作生产版本事实。
- 不授权管理台自更新；聚蚁生产只能使用私有 CI 生成的不可变镜像。
- 不把上游 `main` 的未发布提交当作正式版本；日常更新只合并最新 release tag。
- 本次建库不部署、不切换生产、不修改业务行为。

## 维护边界

源章节表格是派生图谱的事实来源。修改模块、任务或边界时，先改第 06/11/17 节，再运行 `_run/build_vault.py`。代码位置、实施沉淀和验证记录只写在派生笔记的受保护标记之间。
